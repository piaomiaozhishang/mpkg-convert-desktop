# 场景特效可行性与本次修复

## 结论

本次修复的是静态场景合成，输出 PNG；已有 MP4 仍按原字节导出。动态场景转视频在技术上可行，但需要连续渲染场景、处理特效和音频，再编码 MP4。本版没有实现完整动态场景转视频，不能保证静态输出与 Wallpaper Engine 任意时刻的截图一致。

Wallpaper Engine 官方说明：场景没有固定的起止时间，还可能包含随机和交互行为。需要完整视觉效果时，可以通过原引擎“在窗口中播放”并录制；循环接缝需要另外处理。参见 [官方导出说明](https://help.wallpaperengine.io/en/functionality/export.html)。

## 用户样本

验证样本：`scene.pkg`，26,100,554 字节，PKGV0009，81 个条目，画布 3840×2160。样本不随源码分发。

场景含 5 个图片图层、4 个粒子对象、1 个音频对象。图片图层上共 24 个启用的效果实例：Opacity 2、Pulse 5、God Rays 1、Water Waves 6、Water Ripple 1、Shake 9；另启用相机视差。其中一个 Pulse 使用音频响应参数。

两张 Opacity 遮罩过去被全部排除，导致人物、头发层的叠加不正确。本次按包内 `opacity.frag` 的规则应用遮罩红通道：`输出 alpha = 原 alpha × 遮罩红通道 × 效果 alpha`，并按纹理尺寸做双线性采样。图层整体 alpha 在叠加时另外生效。

## 各类效果的判断

以下难度和实现路径是根据样本结构、包内 shader 与官方效果说明作出的工程评估，并非已经完成的功能。

| 效果 | 当前版本 | 转成视频的可行性及约束 |
|---|---|---|
| 图层尺寸、位置、旋转、缩放、隐藏、透明度、基础颜色 | 已支持静态值 | 关键帧插值可做；脚本、父子变换需要另行实现 |
| Opacity 透明度遮罩 | 已支持此类遮罩和保存的 alpha | 静态遮罩可直接复用；动态 alpha 需逐帧求值 |
| Pulse 脉冲、灯光闪烁 | 未渲染 | 可实现，但需要时间、噪声纹理、遮罩和着色参数；音频驱动实例还需要频谱数据 |
| Water Waves 水波、头发飘动 | 未渲染 | 可实现 UV 位移；要匹配原作，必须保留方向、速度、相位、遮罩与效果顺序 |
| Water Ripple 涟漪 | 未渲染 | 可实现法线纹理驱动的 UV 扰动；须还原纹理寻址与动画参数 |
| Shake 呼吸、身体抖动 | 未渲染 | 可实现局部变形；样本有多个遮罩和不同方向组合，不能只让整张图平移 |
| God Rays 光束 | 未渲染 | 可实现，但需降采样、投射、模糊、合成等多 pass 流程，计算量较大 |
| Dust / Ash 粒子 | 未渲染 | 可实现独立粒子模拟；要固定随机种子、预热、发射速率和生命周期；随意添加飘点不等于还原原效果 |
| 相机视差、鼠标交互 | 仅保存位置 | 可录制或设定一条输入轨迹；MP4 不能继续响应观众的鼠标 |
| 音频响应、音轨 | PNG 不包含 | 可把指定音轨的频谱驱动画面并合成音频；视频不能继续实时响应电脑播放的其他音乐 |
| 时间线、骨骼、SceneScript、3D、自定义 shader | 不完整支持 | 需要动画系统、脚本环境或兼容渲染器。原引擎播放并录制是更可靠的还原路径 |

官方效果类别和用途见 [Effects Overview](https://docs.wallpaperengine.io/en/scene/effects/overview.html)，脚本交互能力见 [SceneScript Reference](https://docs.wallpaperengine.io/en/scene/scenescript/reference.html)。

## 视频输出需要补齐的工程

1. 解析场景依赖，区分包内资源和原引擎自带资源；样本引用 `util/noise`、`util/clouds_256`、`util/white` 等共享资源，包内并不齐全。
2. 实现 GPU 渲染目标、效果顺序、shader 宏和采样规则；逐帧驱动动画和粒子。仅用 FFmpeg 把静态 PNG 重复编码不能补回这些效果。
3. 指定时长、帧率、分辨率和输入轨迹，连续将帧送给编码器，编码 H.264/MP4，再处理音轨和循环接缝。
4. 支持取消、临时文件提交、显存/内存上限、异常回收，并用原引擎固定时间截图做对照。

4K RGBA 一帧约 31.6 MiB；30 秒、30 fps 共 900 帧，全部驻留约 27.8 GiB。因此需要流式编码和有界缓存，不能先把全部帧留在内存。本机本次没有运行重负载视频渲染。

## 本次程序改动

- Windows 导入文件、选择输出目录均接入系统 IFileOpenDialog，支持固定目录导航、搜索、文件筛选和多选；取消不视为错误。
- 文件定位改用 Shell API，避免 explorer 参数中的中文、空格、逗号问题；找不到文件时尝试打开现存父目录。
- “跳过已有文件”保留实际主输出路径，文件夹按钮仍可定位；修复任务双击回调捕获旧状态的问题。
- 合成优先使用场景声明的画布尺寸，按图层自身尺寸放置，转换 Y 轴方向；遵守保存的隐藏状态，支持整体透明度、基础颜色、背景色和 Opacity 遮罩。
- 多个图层引用同一纹理时仍进入合成；纹理引用保留子目录，避免同名资源冲突。
- 未渲染效果逐项列入可展开的合成说明；不会把粒子、音频等遗漏都笼统算成图片图层。
- 安装许可页改为简洁中文说明和 MIT 原文；详细来源、组件许可随安装目录保存。
